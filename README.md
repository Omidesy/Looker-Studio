Дашборд аналізу продажів інтернет-магазину (SQL + Looker Studio). Об'єднання даних онлайн- та офлайн-продажів через SQL-запит (LEFT JOIN, UNION ALL), розрахунок KPI (дохід, кількість клієнтів/товарів/міст), сегментація за рівнем лояльності, географічна візуалізація. Дохід за замовчуванням враховує лише успішні платежі (фільтр "Статус платежу: Оплачено"). Дані — навчальний датасет GoIT.
Інструменти: SQL (PostgreSQL-синтаксис), Looker Studio
